## Tentang

Nyawit Pro adalah tools otomatisasi Facebook lengkap dengan tampilan modern dan fitur terintegrasi dalam satu dashboard.

## Fitur

### Profile & Account
- Grab UID
- Add Teman Massal
- Auto Konfirmasi Pertemanan

### Posting
- Posting Foto
- Tag Teman
- Posting Group

### Group
- Dump Group by Query
- Kirim Pesan Group
- Auto Gabung Group
- Auto Keluar Group

### Lainnya
- Dump Friends
- Dump Suggest
- Dump Publik

---

## Keterangan Fitur

| Fitur | Deskripsi |
|---|---|
| Grab UID | Ambil UID dari teman, suggest, dan publik |
| Add Teman | Kirim request pertemanan massal |
| Konfirmasi Pertemanan | Auto konfirmasi request masuk |
| Posting Foto | Upload foto ke timeline dengan caption |
| Tag Teman | Tag banyak teman di postingan |
| Posting Group | Posting otomatis ke grup Facebook |
| Dump Group | Ambil daftar grup berdasarkan keyword |
| Kirim Pesan Group | Kirim pesan massal ke teman atau users publik |
| Gabung Group | Auto join grup |
| Keluar Group | Auto leave grup |
| Dump Friends | Ambil semua ID teman |
| Dump Suggest | Ambil ID friend suggestion |
| Dump Publik | Ambil daftar teman dari profil publik |
